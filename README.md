# 家庭维修事项

端口规划：`5114`

```bash
npm install
npm run dev
```

第一版闭环：记录维修问题、按状态查看、更新处理状态、统计未完成预计费用，支持照片链接并使用localStorage保存数据。

第二版：事项支持标签（新增时多个标签用逗号分隔），列表展示标签，列表上方可按标签筛选或查看全部，标签与筛选状态随localStorage持久化，刷新后保持。

修复：标签值可以是任意文本（包括 all），「全部标签」按钮改用独立哨兵值并随存储版本迁移，任意标签都能单独筛选。
